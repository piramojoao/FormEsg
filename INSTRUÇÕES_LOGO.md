# 🏢 Instruções Para Adicionar a Logo do Instituto Company

## 📥 **PASSO A PASSO (2 minutos):**

### **1. Salvar a Logo**
Na imagem que você enviou:
1. **Clique com botão direito**
2. **"Salvar imagem como..."**
3. **Nome**: `logo-instituto-company.png`
4. **Salvar**: Desktop (temporário)

### **2. Colocar no Projeto**
1. **Abra a pasta**: `FormIago/public/assets/`
2. **Cole o arquivo**: `logo-instituto-company.png`

### **3. Resultado Final**
```
FormIago/
├── public/
│   ├── assets/
│   │   └── logo-instituto-company.png ✅
│   └── index.html
└── src/
```

### **4. Testar**
```bash
npm start
```
**Acesse**: `http://localhost:3000`

## ✨ **A Logo Vai Aparecer:**

```
┌─────────────────────────────────────────┐
│         [LOGO INSTITUTO COMPANY]        │
│  ─────────────────────────────────────  │
│          🌱 DIAGNÓSTICO ESG             │
│                                         │
│  Olá! Sua participação é fundamental... │
└─────────────────────────────────────────┘
```

## ❓ **Se a Logo Não Aparecer:**

### **Verificar:**
1. ✅ Nome EXATO: `logo-instituto-company.png`
2. ✅ Local EXATO: `FormIago/public/assets/`
3. ✅ Recarregar página: `Ctrl + F5`

### **Problemas Comuns:**
- ❌ Nome errado: `instituto-company.png` (falta "logo-")
- ❌ Local errado: `FormIago/src/` (deve ser `public/assets/`)
- ❌ Cache: Recarregue com `Ctrl + F5`

## 🎨 **Especificações da Logo:**

### **Tamanho Automático:**
- **Altura máxima**: 60px (desktop) / 45px (mobile)
- **Largura máxima**: 180px (desktop) / 140px (mobile)
- **Proporção**: Mantida automaticamente

### **Formatos Aceitos:**
- ✅ **PNG** (recomendado - fundo transparente)
- ✅ **JPG** (fundo branco)
- ✅ **SVG** (melhor qualidade)

## 📱 **Responsivo:**
- **Desktop**: Logo centralizada, 60px altura
- **Mobile**: Logo menor, 45px altura
- **Tablet**: Ajuste automático

## 🚀 **Depois de Adicionar:**

1. **Reinicie**: `npm start`
2. **Teste**: Acesse o formulário
3. **Deploy**: Faça build e suba no servidor
4. **Compartilhe**: Envie links para stakeholders
