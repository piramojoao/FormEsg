# 🎨 Gradientes Disponíveis - Suas Cores Personalizadas

## 🌟 **Gradiente Atual (Ativo):**
```css
linear-gradient(135deg, #398226 0%, #679e26 50%, #3c7a2a 100%)
```
✅ **Transição:** Verde Principal → Verde Claro → Verde Escuro  
🎯 **Direção:** 135° (diagonal)  
✨ **Efeito:** Suave e profissional com 3 tons

---

## 🔄 **Outras Opções de Gradientes com Suas Cores:**

### 1. **Gradiente Vertical** ⬇️
```css
linear-gradient(180deg, #398226 0%, #679e26 50%, #3c7a2a 100%)
```
De cima para baixo

### 2. **Gradiente Horizontal** ➡️
```css
linear-gradient(90deg, #398226 0%, #679e26 50%, #3c7a2a 100%)
```
Da esquerda para direita  

### 3. **Gradiente Radial** ⭕
```css
radial-gradient(circle, #398226 0%, #679e26 40%, #3c7a2a 100%)
```
Efeito circular do centro

### 4. **Gradiente Invertido** 🔄
```css
linear-gradient(135deg, #3c7a2a 0%, #679e26 50%, #398226 100%)
```
Ordem invertida das cores

### 5. **Gradiente Só 2 Cores** 🎭
```css
linear-gradient(135deg, #398226 0%, #3c7a2a 100%)
```
Mais simples, sem o meio

### 6. **Gradiente Conic** 🌀
```css
conic-gradient(from 0deg, #398226 0%, #679e26 120%, #3c7a2a 240%, #398226 360%)
```
Efeito espiral/circular

## 🛠️ **Como Trocar o Gradiente:**

### **Opção 1: Via Arquivo CSS**
Edite `src/styles/colors.css` linha 15:
```css
--background-gradient: SEU_GRADIENTE_AQUI;
```

### **Opção 2: Via public/index.html**
Edite linha 21:
```css
background: SEU_GRADIENTE_AQUI;
```

### **Opção 3: Via App.css (botão)**
Edite linha 108:
```css
background: SEU_GRADIENTE_AQUI;
```

Use gradientes com contraste para destacar ações

### **Para Fundos:**
Prefira ângulos diagonais (135deg, 45deg) - mais modernos
